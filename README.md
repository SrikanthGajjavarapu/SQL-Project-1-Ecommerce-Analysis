# E-Commerce Sales Data Analysis Using SQL

## Project Overview
This project focuses on analyzing e-commerce sales data using MySQL 8.0+. The objective is to extract meaningful business insights from customer, product, order, and order details data using SQL queries.

The analysis helps understand sales performance, customer purchasing behaviour, product performance, and revenue trends.

## Tools & Technologies
- MySQL 8.0+
- MySQL Workbench
- SQL

## Database Structure

The project contains four main tables:

1. **Customers** – Stores customer details such as customer ID, name, and city.
2. **Products** – Stores product information, including product ID, product name, and category.
3. **Orders** – Contains order details such as order ID, customer ID, order date, order status, and total amount.
4. **OrderDetails** – Contains product-level order information, including quantity and price.

## SQL Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT, AVG)
- INNER JOIN
- Common Table Expressions (CTEs)
- CASE WHEN statements
- Window Functions
- DENSE_RANK()
- LAG()
- Subqueries

## Business Questions Answered

1. What is the total revenue generated from delivered orders?
2. Who are the top 5 customers based on revenue?
3. What is the distribution of orders by order status?
4. Which products generate the highest revenue?
5. What is the revenue generated by each product category?
6. What is the monthly sales performance?
7. How many customers have placed orders?
8. What is the average delivered order value?
9. Which cities generate the highest revenue?
10. How can products and customers be ranked based on sales performance?

## Key Business Insights

- Identified top-performing customers based on delivered revenue.
- Analysed product and category-wise sales performance.
- Evaluated monthly revenue trends.
- Compared revenue performance across different cities.
- Used SQL ranking functions to identify high-performing products and customers.

## Project Objective

The main objective of this project is to develop practical SQL data analysis skills and demonstrate the ability to transform raw e-commerce data into meaningful business insights.

SQL Query Writing | Data Analysis | Data Aggregation | Data Cleaning Concepts | Business Insights | Data Reporting
